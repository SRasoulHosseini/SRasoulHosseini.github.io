# Seyed Rasoul Hosseini Personal Website

A responsive, dependency-free academic website built with HTML, CSS, and JavaScript.

## Preview locally

Open `index.html` directly, or run a local static server from this folder:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy

Upload the contents of this folder to GitHub Pages, Netlify, Cloudflare Pages, or any static web host. No build step is required.

## Update content

- Page content and links: `index.html`
- Colors and layout: `styles.css`
- Navigation, theme, and reveal behavior: `script.js`
- Downloadable CV: `assets/Seyed_Rasoul_Hosseini_CV.pdf`
- Portrait: `assets/portrait.jpg`

After choosing a deployment domain, replace the relative Open Graph image path in `index.html` with its absolute public URL for the most reliable social-media preview.
